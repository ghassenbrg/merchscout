# Marketplace Language Rules

Configured marketplaces are in `assets/marketplace-config.json`: US, UK, DE, FR, IT, ES, and JP.

Rules:

- Use natural localized listing copy for each selected marketplace.
- Do not literal-translate jokes when the result is awkward.
- If a phrase only works in English, prefer US/UK or use a no-text design for other marketplaces.
- For JP, prefer natural Japanese or no visible text; English can be acceptable for tech or fashion concepts when intentional.
- Do not include competitor brands, franchise names, celebrities, sports teams, official/licensed claims, or unrelated keywords.
- Keep field limits configurable because Amazon UI limits can vary by product/category/marketplace/account.
